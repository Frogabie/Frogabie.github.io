Privacy policy

Last updated: 21 November 2026

What this tool is

The How It's Built publishing tool is a private program used only by the owner of the How It's Built YouTube channel to upload that channel's own videos. It has no other users.

What it accesses

With the channel owner's permission, given through Google's sign-in screen, the tool uses the YouTube Data API to:

  • upload and schedule videos on the owner's channel,
  • read the channel's name and its list of uploaded videos, and
  • update the channel's banner and description.

Where data is kept

The sign-in token Google issues is stored only on the channel owner's own computer. The tool does not collect, sell, share or send any personal data to anyone other than Google's YouTube service, and it collects no data about viewers.

Removing access

The channel owner can revoke the tool's access at any time at myaccount.google.com/permissions.

YouTube and Google

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Contact

Questions can be sent through the How It's Built YouTube channel.
